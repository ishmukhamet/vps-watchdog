# Configuration

## Config file

Default path:

```text
/etc/vps-watchdog/config.yaml
```

The MVP parser supports the simple key/value structure generated by the
installer. Do not use advanced YAML features such as anchors, arrays, multiline
strings, or nested objects beyond the documented shape.

`validate-config` checks the documented shape, required values, and threshold
ranges. It does not prove that Telegram credentials are valid or that Telegram is
reachable; use `test-notify` for that end-to-end check.

## Telegram

```yaml
telegram:
  token_file: /etc/vps-watchdog/telegram.token
  chat_id_file: /etc/vps-watchdog/telegram.chat_id
```

Secrets should be stored in files rather than in the config itself.

Expected permissions:

```text
-rw-r----- root vpswatchdog /etc/vps-watchdog/telegram.token
-rw-r----- root vpswatchdog /etc/vps-watchdog/telegram.chat_id
```

## Load thresholds

```yaml
load:
  enabled: true
  sample_interval_sec: 15
  cooldown_sec: 900
  cpu_busy_percent: 90
  cpu_duration_sec: 180
  mem_available_percent: 10
  mem_duration_sec: 180
  psi_io_some_avg60: 20
  io_duration_sec: 180
```

Thresholds are duration-based. A single spike should not alert unless it remains
above threshold for the configured duration.
